# Оно тебе надо

Одностраничный сайт аукциона вещей, в которые никто не верил. Первая проектная
работа первого спринта курса «Фулстек-разработчик расширенный» Яндекс Практикума.

## Ссылки

- Репозиторий: https://github.com/fomashuk-svg/ono-tebe-nado-fd
- Макет: https://www.figma.com/design/c8DCTfFp8Ae7j6bvOq7S35/

## Стек

- Семантическая HTML5-разметка
- Grid — шапка, подвал, секция «Об аукционе»
- Flexbox — меню, список карточек, контакты, внутренняя раскладка карточки
- БЭМ для именования классов
- Локально подключённый Raleway в форматах woff2 и woff

## Структура

- `index.html` — разметка страницы
- `fonts/` — шрифты и `fonts.css` с `@font-face`
- `styles/global.css` — сброс браузерных стилей и общие настройки
- `styles/style.css` — стили проекта
- `images/` — изображения макета
